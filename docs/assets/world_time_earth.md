# World Time Earth texture

`WorldTimeEarthTexture` creates the equirectangular bitmap in project code from ocean, grid, continent silhouettes and polar ice. It is an original launcher asset created for this project; it does not include, copy, derive from or depend on SPB Shell assets or third-party imagery. The renderer caches it under `world-time-earth-v1` and recreates the GL texture after an EGL context recreation.
